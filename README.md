# CTL-SLITTER (AI Optimizer)

An intelligent optimization system for Cut-To-Length (CTL) operations that optimizes the assignment of hot-rolled coils to CTL lines while fulfilling sales orders with minimum scrap.

## Features

- **Coil Management**: Track and manage raw material inventory (hot-rolled coils)
- **Order Management**: Handle sales orders and sheet requirements
- **Line Management**: Configure CTL lines and their specifications
- **AI Optimization Engine**: Intelligent assignment algorithm to minimize scrap
- **Dashboard & Analytics**: Comprehensive results analysis and reporting
- **RM Forecasting**: Predictive recommendations for raw material purchases

## Tech Stack

- **Framework**: Next.js 16.0.10
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Charts**: Recharts
- **Forms**: React Hook Form with Zod validation

## Getting Started

### Prerequisites

- Node.js 18+ 
- pnpm (recommended) or npm

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd CTL-Optimizer
```

2. Install dependencies
```bash
pnpm install
```

3. Run the development server
```bash
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage

1. **Setup**: Start with the Setup tab to understand the workflow
2. **Lines**: Define your CTL lines and specifications
3. **Coils**: Add available coils from your raw material inventory
4. **Orders**: Input sales orders and sheet requirements
5. **Optimize**: Run the AI optimization engine
6. **Results**: Review assignments and scrap analysis
7. **Forecasting**: Check recommended RM purchases

## Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm start` - Start production server
- `pnpm lint` - Run ESLint
